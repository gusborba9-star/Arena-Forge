# Stage Execution Protocol

Para toda etapa: criar/adaptar; eliminar legado; executar testes; validar resultado; corrigir qualquer falha; repetir testes; registrar evidência; atualizar roadmap; só então iniciar a etapa seguinte.

CI verde é necessário, mas não suficiente: também são avaliados arquitetura, regressão, segurança, custo e impacto de produto.
