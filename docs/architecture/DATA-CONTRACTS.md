# Data Contracts

Card: id, name, rarity, type, energy_cost, cooldown, target_type, effects, unlock_arena, progression, balance_parameters.
Arena: id, environment, terrain, hazards, elements, tile_types, environmental_rules, events, enemy_pool, spawn_rules, destructibles, unlock_requirement, special_rules.
Hero: id, role, hp, damage, speed, armor, ability.

O núcleo deve permanecer estável enquanto o conteúdo cresce de 16 para 40, 80, 150+ cartas.
